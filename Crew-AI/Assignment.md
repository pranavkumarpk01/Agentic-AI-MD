# Assignment 1 – Multi-Agent System

## Project Title
Smart Event Planning Assistant

### Problem Statement

Build a Multi-Agent System that helps users plan events such as birthdays, corporate gatherings, workshops, weddings, or celebrations based on budget, preferences, and attendee count.

The system should coordinate multiple agents to generate a complete event plan.

---

### Suggested Agents

#### Venue Discovery Agent
Find suitable venues based on:
- Budget
- Event type
- Number of attendees

#### Budget Planning Agent
Create:
- Estimated cost breakdown
- Expense categories
- Cost optimization suggestions

#### Vendor Coordination Agent
Recommend:
- Catering options
- Decoration services
- Photography services
- Entertainment options

#### Schedule Management Agent
Generate:
- Event timeline
- Activity schedule
- Setup and closing activities

---

### Expected Output

A complete event planning report containing:

- Venue Recommendation
- Budget Summary
- Vendor Suggestions
- Event Schedule
- Final Recommendations

---

### Project Clues

💡 Think about how one agent's output can become another agent's input.

💡 Create a shared state object that stores information generated by each agent.

💡 Allow agents to exchange information instead of working independently.

💡 Try implementing a coordinator agent that manages the workflow.

💡 Consider how conflicts can be resolved when two agents provide contradictory recommendations.

💡 Design the system so that new agents can easily be added later.

# Assignment 2 – Multi-Agent System

## Project Title
AI Travel Planning Consultant

### Problem Statement

Build a Multi-Agent Travel Consultant capable of creating complete travel plans based on user preferences.

The system should help users decide:

- Where to travel
- How to travel
- Where to stay
- What to do each day

---

### Suggested Agents

#### Destination Advisor Agent

Responsible for:
- Destination recommendations
- Seasonal suitability
- Matching user interests

#### Transportation Agent

Responsible for:
- Travel route planning
- Transportation recommendations
- Cost estimation

#### Accommodation Agent

Responsible for:
- Hotel recommendations
- Budget matching
- Stay optimization

#### Itinerary Planner Agent

Responsible for:
- Day-wise planning
- Activity scheduling
- Time optimization

#### Travel Risk Advisor Agent

Responsible for:
- Travel advisories
- Risk identification
- Backup recommendations

---

### Expected Output

A complete travel plan containing:

- Destination Recommendation
- Budget Estimate
- Accommodation Plan
- Daily Itinerary
- Travel Tips

---

### Project Clues

💡 Use a central workflow manager to decide which agent should run next.

💡 Think about situations where one agent may need additional information from another.

💡 Store travel preferences in a shared memory structure.

💡 Consider implementing dynamic routing where different destinations trigger different workflows.

💡 Design agents to be reusable across multiple travel scenarios.

💡 Bonus challenge: Allow users to modify the itinerary and regenerate only affected sections.

# Assignment 3 – CrewAI

## Project Title
Personal Finance Management Crew

### Problem Statement

Develop a CrewAI application that analyzes a user's monthly spending habits and generates financial insights and recommendations.

The objective is to help users better understand their spending patterns and improve financial planning.

---

### Suggested Crew Members

#### Expense Analyzer

Responsibilities:
- Analyze spending categories
- Detect spending patterns
- Highlight major expenses

#### Savings Advisor

Responsibilities:
- Identify saving opportunities
- Recommend monthly savings goals
- Suggest emergency fund planning

#### Investment Planner

Responsibilities:
- Suggest investment allocation
- Explain risk levels
- Recommend diversification approaches

---

### Expected Output

The system should generate:

- Expense Analysis Report
- Spending Insights
- Savings Recommendations
- Investment Suggestions

---

### Project Clues

💡 Explore how task outputs can be passed as context to subsequent tasks.

💡 Think carefully about task sequencing.

💡 Experiment with different agent roles and backstories.

💡 Store intermediate results and reuse them across tasks.

💡 Try creating reusable task templates.

💡 Consider how CrewAI memory can improve recommendations over time.

💡 Bonus challenge: Generate personalized recommendations based on user goals.

# Assignment 4 – CrewAI

## Project Title
Autonomous Startup Launch Consultant

### Problem Statement

Create a CrewAI application that evaluates a startup idea and generates a launch strategy.

The system should act like a virtual consulting team helping founders validate and launch their businesses.

---

### Suggested Crew Members

#### Opportunity Analysis Agent

Responsibilities:
- Understand the startup idea
- Identify customer problems
- Define value proposition

#### Market Intelligence Agent

Responsibilities:
- Analyze competitors
- Assess market demand
- Identify opportunities

#### Revenue Strategy Agent

Responsibilities:
- Explore pricing models
- Define revenue streams
- Suggest monetization approaches

#### Growth Strategy Agent

Responsibilities:
- Create customer acquisition plan
- Recommend marketing channels
- Design growth roadmap

#### Executive Summary Agent

Responsibilities:
- Consolidate all findings
- Generate business report
- Present final recommendations

---

### Expected Output

A startup launch report containing:

- Business Idea Evaluation
- Target Audience Analysis
- Market Insights
- Revenue Model
- Go-To-Market Strategy
- Growth Roadmap

---

### Project Clues

💡 Use a hierarchical CrewAI process with a manager agent.

💡 Design tasks so that outputs from earlier tasks directly influence later decisions.

💡 Think about how memory can preserve important business insights throughout the workflow.

💡 Explore using tools such as web search, calculators, or external APIs.

💡 Consider how an executive agent can aggregate outputs from multiple agents.

💡 Build the project so that additional business experts can be added easily in future versions.

💡 Bonus challenge: Generate a downloadable startup proposal in PDF format.

# General Expectations

Students should focus on:

- Agent collaboration
- Workflow orchestration
- State management
- Context passing
- Memory usage
- Task decomposition
- Scalable architecture design

The goal is not just to generate answers, but to design systems where multiple AI agents work together to solve real-world problems efficiently.
